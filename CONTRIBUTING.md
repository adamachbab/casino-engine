# Contributing

- Keep changes focused and match the existing style: lowercase snake_case, readable spacing.
- Run `npm test` in `server/` and build the client in Release before opening a pull request.
- Do not commit binaries, build folders, `.env` files or databases.
- Game rules and payouts must stay server side and provably fair.
- Report security issues privately as described in [SECURITY.md](SECURITY.md).
